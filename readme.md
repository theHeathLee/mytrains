# mytrains

static webpage that shows train departures in my hood

[clickity click me](https://theheathlee.github.io/mytrains/)


### Data

All real-time transport data is sourced from the VBB/BVG via the third-party API: https://v6.vbb.transport.rest.

### Design and Graphics

The visual elements (colors, pattern) are inspired by the official BVG (Berliner Verkehrsbetriebe) design guidelines.

This project provides fair-use attribution and is not intended for commercial use without proper licensing.
